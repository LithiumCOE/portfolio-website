# About Me 项目文字

直接编辑同目录下的 `projects.md`。可以用 Obsidian 的实时预览或其他 Markdown 编辑器，无需改 HTML。

- `**加粗文字**`：加粗。
- `*斜体文字*`：斜体。
- `[文字](https://example.com)`：链接。
- 每个 `- ` 列表项对应网页里的一条项目文字。

示例：

```md
## 柳叶刀工作室

### 设计师

- **三方合作商业FPS项目**局外UX
- 自研FPS **全流程UIUX**
```

二级标题是履历分组，请保留名称：本科、硕士、柳叶刀工作室、网易互娱。
三级标题是项目对应身份：独立游戏开发者、设计师、用户研究员、设计策略；决定这一组项目的颜色与筛选关系。可以在相应身份下面添加、删除或编辑项目列表项，不需要手动设置颜色。

保存后刷新本地页面即可看到。上传并推送到 GitHub 后才会更新公网。
