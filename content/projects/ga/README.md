# GA 项目内容

- `intro.md`：Preview 简介，支持普通 Markdown 与加粗；修改后刷新网页即可。
- `body.md`：按 Figma 空间排版的正文，包含原生 HTML、文字、局部图片和 SVG 连线，不是整张长图。可修改文字；较长文案或结构改动需同时调整对应布局。
- `images/`：Figma 导出的局部素材，来源映射见 `images/ASSET_SOURCES.md`。
- 图集与 Steam 地址：上一级 `projects.json` 中 `id: ga` 的配置。

with MORE Preview 共用标准：1330px 最大宽度；左右 40px，顶部 64px；标题基准 90px、副标题基准 70px，长标题根据类别占用后剩余宽度按比例缩小；类别 32px、正文 16px；正文至少 200px；媒体上间距 45px；MORE 贴首屏底部保留 16px，首屏不足时自然撑高。不同项目不强制使用同一实际标题字号。

GA 正文保持 1330 × 4141 的设计坐标，桌面窗口变窄时等比缩放；正文按块进入弹窗视口后再入场：标题上移与轻微缩放、文字错峰淡入、媒体裁切展开、彩色连线自上而下显现。灰色箭头和背景保持静态；每次重新打开可重新播放，系统减少动态效果设置下直接显示。

Preview 与正文为两个独立阅读状态：MORE 或底部下滚进入正文；正文顶端上滚或 PREVIEW 返回。高保真三稿入场后，前两稿置灰，第三稿放大突出。

## 当前分屏版本
正文渲染由根目录 ga-chapters.js 管理，共六个视口。原始内容仍读取 body.md；切屏支持滚轮、上下键及底部导航。低保真页通过三个页签查看原稿。高保真入场后前两稿缩小移左，第三稿放大；正文位图可点击在二级弹窗查看。首屏上滚返回 Preview，没有 ↑ PREVIEW 文本按钮。
