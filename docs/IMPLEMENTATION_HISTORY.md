# PortfolioWebsite 初步原型

2026-10-14 用户已授权：依据旧 Framer 简报的 IA 制作简要 HTML 骨架，以及微缩城市 Hero 初版，供体验和方向评审。此授权只扩展到探索原型，最终网站仍依据 Figma 交付。

直接打开 index.html 可体验；也可在本目录启动静态预览服务。无外部依赖，无后端，无 WebGL。

- index.html：Hero → About → 三行业入口 → 联系。
- hero.js：Canvas 等距模型；播放/暂停、速度、Boost、超速切线飞出、重置。
- work.html / case.html / pages.js：按行业排序、四种案例浏览行为、概述/演示来回跳转、外链。
- style.css：桌面与手机布局、键盘焦点、减少动态偏好。

Hero 暂定：默认 1× 自动运行；速度超过 2.2× 在转弯处有脱轨风险；Boost 临时提升到 3.6×；Reset 恢复默认速度和位置。系统减少动态偏好下初始及 Reset 后保持暂停。

案例均为明确标注的内容占位，未接入公司素材、真实案例原型或最新简历。主页文案也是方向探索。案例转场暂用正常网页跳转；卡片扩展动效留待设计稿确认。未创建 Git 仓库，未上传或部署。

## 第二版：2026-10-14 用户反馈
首页、About、Category 改为三个独立全屏画面（同一文档，hash 对应地址），支持滚轮、边缘提示、桌面边缘拖动、键盘 PageUp/PageDown；画面内容较长时先在内部滚动。过渡为位移+透明度，减少动态偏好下直接切换。联系方式放入 About。
Hero 改为有上下交叉桥梁的八字闭合路径，按路径长度控制车速。Canvas 以同一等距投影绘制道路与车身：朝向只改变世界水平轴，车顶与车轮高度始终沿世界 Z 轴。无需预绘精灵图，也无 WebGL；当前为程序绘制的模型风格。

## 遮挡修正
道路、桥梁、建筑、树与车辆统一按每个像素的等距相机深度比较，不再分成整层强制覆盖。静态颜色和深度缓存；每帧仅叠加小车。depth-renderer.js 实现软件深度缓冲，依旧使用 Canvas 2D，不依赖 WebGL。

## 实体交互探索
沙盘长边内置速度滑块、红色 Reset、深色 Play/Pause 按钮；按等距空间深度绘制。超速后可直接捡起小车，拖进沙盘上方虚线回收区域后松手归位；区域外松手不会恢复。失控车辆的位置限制在可见范围，便于拾取。原 DOM 控件折叠为键盘/备用控制；PNG 生成和下载保持可用。

赛道回收更新：拖拽时整条赛道高亮，最近合法落点显示圆环。松手后从该落点以 1× 继续跑；轨道外松手不恢复。脱轨与拾取车作为前景恢复对象，正常行驶恢复空间深度。Reset 下压后回弹；Pause 暂停时下压、播放时弹起。

水平旋转：在 Canvas 内非控件、非拾取小车的位置左右拖动，可以绕垂直轴旋转整个沙盘。相机投影、像素深度、控件逆投影与赛道回收路径同步更新；PNG 导出使用当前角度。

旋转修订：已删除沙盘底部的平面假阴影；水平拖动与相机旋转的映射方向已反转。

## WebGL 探索版
用户已授权备份后试作 WebGL。当前首页使用 webgl-hero.js + vendor/three.module.js / three.core.js（Three.js 0.186.1，MIT）。真正的三维几何、光照、阴影、射线拾取；原调速、播放/暂停、超速脱轨、拖回任意轨道位置、旋转、按钮下压与 PNG 导出保持，红/绿按钮新增 Hover 提示。Canvas 2D 已完整冻结在 backups/canvas2d-2026-10-14/，可单独打开其 index.html 对照；outputs 内有 ZIP 备份与验收说明。未部署。

WebGL 遮挡修订：取消脱轨小车的独立置顶场景。车、车轮、建筑、道路、桥梁与实体控件均为真实 3D 网格，共用 GPU 深度。脱轨车沿立体飞行弧线落到沙盘外沿的木质停靠台；拾取时在真实三维高度平面上移动，不清空深度。拖动旋转方向已反转。

桌面修订：删除动态生成的脱轨停靠木台和引导落点。改为统一的固定三维桌面（位于沙盘底座底部 Y=-16），接收真实光照阴影。车辆沿切线抛出、自然落地减速，不再突然产生独立底座；可以从落点拾回赛道。
